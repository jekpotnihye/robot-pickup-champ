One pickup line in the voice of a robot, at most 200 characters:

> My battery just dropped to 2%, and I'd still burn my last percent calculating the odds you'll say hi back.

## Run it

```sh
node main.ts
```

It writes the line, with no trailing newline, to `/output/entry.txt` (106 characters).
